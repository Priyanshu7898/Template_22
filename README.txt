APPIES REACT REFERENCE PAGE

This project displays the exact page image extracted from your supplied PDF.
It is responsive and uses React + Vite.

Run:
1. Install Node.js if it is not installed.
2. Extract this ZIP.
3. Open the extracted folder in VS Code.
4. Open the terminal in that folder and run:
   npm install
   npm run dev

Note:
This version reproduces the supplied PDF visually by displaying the original page image.
The text, buttons, and sections are not separate editable React elements.
For a fully editable, pixel-matched HTML recreation, the original individual image assets
(phone mockups, backgrounds, screenshots, and icons) would be needed.
